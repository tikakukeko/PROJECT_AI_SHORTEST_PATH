# UNIB SmartRoute

UNIB SmartRoute adalah aplikasi navigasi kampus berbasis web yang menggunakan algoritma A* (A-Star) untuk mencari jalur terpendek antar lokasi di Universitas Bengkulu. Sistem ini memanfaatkan data graf dan heuristik Haversine untuk menghasilkan rute yang optimal serta menampilkan hasil pencarian pada peta interaktif.

### Fitur Utama

* Pencarian jalur terpendek menggunakan algoritma A*.
* Visualisasi rute pada peta interaktif berbasis Leaflet.js dan OpenStreetMap.
* Estimasi jarak dan waktu tempuh.
* Pilihan mode perjalanan (Jalan Kaki dan Motor).
* Deteksi lokasi pengguna (GPS).
* Dark Mode dan pilihan tampilan peta.
* Panduan rute langkah demi langkah.

### Struktur Project

* **index.html** → Tampilan utama aplikasi.
* **style.css** → Desain dan tampilan antarmuka.
* **script.js** → Logika aplikasi, implementasi algoritma A*, data graf, dan fitur navigasi.

Proyek ini dikembangkan sebagai implementasi konsep Artificial Intelligence pada permasalahan pencarian jalur (pathfinding) dalam lingkungan kampus.
